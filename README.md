# Files — website

The landing page for [Files](https://github.com/FileForce/files): Next.js
(App Router), Tailwind CSS and Motion. Fully static, no backend.

```sh
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # production build
```

Deploys to Vercel as is (framework preset: Next.js). Animations follow the
visitor's "reduce motion" setting.

Favorites used to be for folders. Now any file can sit there too: right-click it and choose **Add to Favorites**.

- **Click** opens it in its app, like a double-click in the list.
- **Middle-click** — or **Show in Folder** in its menu — opens the folder it lives in, with the file selected.
- It shows **its own icon**: a spreadsheet looks like a spreadsheet, a Windows game like the game.

If the file is moved or deleted, its row turns faint instead of disappearing, so you notice; **Remove from Favorites** in the same menu takes it out.

<Callout title="Tip">
Favorites are kept in your settings, so they survive updates — and the order is the order you added them.
</Callout>

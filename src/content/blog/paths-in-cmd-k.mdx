<Kbd>⌘</Kbd> <Kbd>K</Kbd> (<Kbd>Ctrl</Kbd> <Kbd>K</Kbd> on Windows and Linux) searches everywhere — and it also knows a path when it sees one. Paste it and the first result is that folder; <Kbd>Enter</Kbd> opens it. A file opens its folder with the file selected.

All of these work:

```text
~/Projects/files
/var/log
C:\Users\me\Downloads
"/Users/me/My Documents"          ← quotes from a terminal are fine
file:///Users/me/Music
```

## Half a path completes

Type `~/Do` and you get **Documents** and **Downloads**. End with a slash — `~/Projects/` — and you see the folder itself first, then the folders inside, so you can walk down without leaving the keyboard.

With a **Music** tab in front, the keyboard works on your tracks:

| Key | Does |
| --- | --- |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd> | the previous / next track |
| <Kbd>Home</Kbd> <Kbd>End</Kbd> | the first / last track |
| <Kbd>PgUp</Kbd> <Kbd>PgDn</Kbd> | a page up / down |
| <Kbd>Enter</Kbd> | plays the selected track |
| <Kbd>Space</Kbd> | shows it big: cover, title, artist, album, length |

The selected track has an accent bar at its left; the playing one keeps its ▶. All of these are in **Settings → Hotkeys → Music**, if you would rather use other keys.

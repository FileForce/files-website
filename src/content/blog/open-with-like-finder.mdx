Right-click a file → **Open With**, and you see what Finder shows:

1. **The default app**, marked *(default)*.
2. **Every other app that can open this kind of file** — for a `.pptx` that might be Keynote, LibreOffice and more.
3. **Choose Application…** for anything else.

<Callout title="Why an app may be missing elsewhere">
macOS's own *Choose Application* dialog hides apps you downloaded but never opened (they are still "quarantined"). Files asks the system for every app that registered the file type, so they are listed — open one once from Finder and macOS shows it everywhere too.
</Callout>

Files has its own look. For many people a file manager should simply look like the system around it — so there are two new themes in **Settings → Appearance → Theme**.

| | Windows | macOS |
| --- | --- | --- |
| Colors | Windows 11's Fluent greys and blue | macOS window and sidebar greys, system blue |
| Font | Segoe UI | the system font |
| Corners | 4 / 8 px | 6 / 10 px, like Finder |
| Accent | Azure, Iris, Amber → blue, purple, orange from Windows' palette | the same, from Apple's palette |

Both come in light and dark, so **System** still follows the time of day. And they work everywhere: the Windows theme on a Mac, if that is what you are used to.

## Any font

Right below, **Font** lists every font installed on your computer. Start typing to search — "Inter", "JetBrains", "Georgia" — and a sample next to the list shows it before you save. **Theme default** gives the choice back to the theme: Segoe UI for Windows, the monospace of Omarchy, the system font for the rest.

<Callout title="Tip">
A wider font makes long names wrap sooner in the grid. If names get cut, the Pro list (<Kbd>⌘</Kbd> <Kbd>2</Kbd>) shows them in full.
</Callout>

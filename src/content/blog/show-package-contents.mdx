On a Mac, many "files" are really folders — **packages**: every `.app`, installers, Xcode projects, the Photos library, Keynote, Pages and Numbers documents. Finder shows them as one item, and now Files does too:

- An app shows **its own icon** and **its size**, and a **double-click starts it** — like an `.exe` on Windows.
- A Keynote or Pages document opens in its app; an Xcode project opens in Xcode.

## Going inside

Sometimes you need what is in there — an app's resources, a library's files. Right-click it → **Quick Actions → Show Package Contents**, and the package opens as a folder in a new tab.

<Callout>
Frameworks stay folders, as in Finder. On Windows and Linux nothing changes: these are ordinary folders there.
</Callout>

- **Several SSH servers at once:** each connected server has its row in the sidebar, and **SSH · Another…** connects one more. `/home/me` on two servers is two folders, in any tab. Disconnecting one leaves the others.
- **Server to server:** drop a file from one server into a folder on another, and Files copies it across.
- **Archives by content:** Docker Desktop's `.dockerbuild.zip` is really a tar.gz, and used to say "cannot read archive". The first bytes now decide; the name is only a fallback.
- **Windows: drag files out** of Files into Telegram, Explorer or mail. It never worked on Windows before.
